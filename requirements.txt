# --- Núcleo de dados ---------------------------------------------------------
pandas
numpy

# --- Formato de troca --------------------------------------------------------
# Parquet preserva tipo (data, decimal, categórico) — coisa que CSV perde. Foi
# escolhido como fronteira com o R, que acabou não entrando no projeto
# (AGENTS.md § A linguagem que ficou de fora), e ficou por preservar os tipos.
pyarrow

# --- Modelagem de crédito ----------------------------------------------------
# optbinning: binning ótimo, WOE/IV e construção de scorecard. É a biblioteca
#   que justifica trazer Python para este projeto — não há equivalente em R com
#   o mesmo nível de maturidade.
optbinning
# scikit-learn: partição, pipelines, métricas, calibração.
scikit-learn
# statsmodels: regressão logística COM p-valor e intervalo de confiança por
#   coeficiente. Em crédito isso não é luxo: um scorecard precisa justificar
#   variável a variável, e o sklearn não reporta significância.
statsmodels
# xgboost e lightgbm: modelos desafiantes (challenger) contra o scorecard
#   logístico. O desafio AutoCred pede explicitamente logística, random forest
#   (vem no scikit-learn) e XGBoost — ver docs/SPEC_01_MODELO_PD.md.
xgboost
lightgbm
# shap: explicabilidade. Modelo de crédito que nega crédito precisa dizer por quê
#   — é exigência regulatória, não enfeite.
shap

# --- Gráficos (dependência do optbinning e diagnóstico rápido) ---------------
matplotlib

# --- Leitura de base em Excel ------------------------------------------------
openpyxl

# --- Dado externo ------------------------------------------------------------
# requests: consulta às APIs públicas do Banco Central (SGS e Olinda), de onde
#   sai a âncora de preço de mercado. O post-mortem registra por que a média do
#   nosso próprio livro não serve como referência de mercado — ver
#   docs/processo/PRD.md § Decisões de modelagem, D1.
requests

# --- Testes ------------------------------------------------------------------
pytest
